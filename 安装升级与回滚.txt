公会炉石：安装、更新和回滚

下载：https://github.com/EclipseCybertitan/AzerothHearth/releases
当前版本：1.2.3。目标：国服“无限”，Interface 16001。
目前界面是中文。提供英文说明不代表其他地区或游戏分支已经兼容。

首次安装
1. 下载 Assets 中的 AzerothHearth-1.2.3-forever.zip 和同名 .sha256。不要下载 Source code，那只是这个指南仓库的快照。
2. 完全退出游戏。已有旧版时，分别备份 AzerothHearth 插件文件夹和本角色 SavedVariables。
3. 核对 SHA-256，把旧插件目录移到 AddOns 之外，再把新 ZIP 内的 AzerothHearth 整个放入所选客户端的 Interface/AddOns。别多套一层文件夹，也别覆盖其他插件。
4. 启动后用 /ah diagnose 检查版本。先请 1–2 人核验加载、登记收发、公报和撤稿，再给其余成员使用。

用 WowUp 更新
Get Addons → Install from URL → 粘贴 https://github.com/EclipseCybertitan/AzerothHearth 。选择自己的 Forever / 无限客户端；识别不出来就手动安装，不要强行选别的游戏分支。
需要自动更新时，在本插件菜单开启 Auto Update。管理器需要运行、网络需要能访问发布源；不是作者直接向你的电脑推送。普通 ZIP URL 只安装一次，不订阅后续版本。
更新前退出游戏并备份。/ah versions 是成员自报版本查询，不是文件校验，也不能把无回应当成没安装。

手动更新与国内网络备用
打不开 GitHub 时，由能下载的维护者通过公会已有的可信文件渠道转交原 ZIP、校验文件和说明。保持原字节，不解压重打包。成员按首次安装步骤完整替换。
不需要租服务器、开放入站端口或做路由器端口映射。下载需要正常 HTTPS 出站访问；各人的网络、代理和组织策略仍可能拦截。不要关闭防火墙或 TLS 校验，也不要共享作者令牌。

回滚
先在 WowUp 关闭 Auto Update 并开启 Ignore，否则可能马上又被升级。退出游戏，另存当前插件和角色存档，再完整安装保留的 1.2.0 或 1.1.0。
1.2.x 与 1.1.0 都使用 schema 2。仅回退插件通常不必同时恢复旧存档；1.1.0 没有新版回执和版本查询。回退 1.0.0 必须恢复配套 schema 1 备份。旧存档可能让撤稿、登记和提醒状态倒退，不要改 schema 数字。
恢复升级时，先确认来源和版本，再取消 Ignore、手动检查更新。

校验命令
Windows PowerShell：Get-FileHash -Algorithm SHA256 -LiteralPath '.\AzerothHearth-1.2.3-forever.zip'
macOS Terminal：shasum -a 256 AzerothHearth-1.2.3-forever.zip
哈希用来检查文件是否一致，不单独证明发布者身份。

常用入口
/ah 打开面板；/ah rp 登记职业 RP；/ah library 阅读全文、归档和更正；/ah delivery 查看客户端回执；/ah versions 查询版本；/ah diagnose 查看诊断。
同步由各成员自行开启，读者需信任公报作者。公报在插件内阅读全文，聊天只由作者手动提醒。回执不是已读；“已收到”和“离线”可以同时成立。

验收范围
已做离线 Lua、安装包和 10 个模拟目录的安装／升级／回滚检查。未打开、读取或复制游戏；真实 WowUp 安装、Win/Mac 游戏运行和各成员网络还没有验收。别把离线结果填成全员实机通过。
记录 10 人的角色代号、系统、版本、备份日期、哈希和实机结果；记录留在公会自己的私有位置。选举规则仍由公会决定。
